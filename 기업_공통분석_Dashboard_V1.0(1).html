기업 공통분석 Dashboard V1.0

목적 : 기업을 심층 분석할 가치가 있는지 1차적으로 판단(GO / WATCH / NO GO)하기 위한 공통분석 템플릿

0. 분석 표준 (Analysis Standard)

분석 기준
  • 분석 기준일
  • 데이터 기준일
  • 모든 수치는 기준 시점 명시
데이터 출처 우선순위
  • 기업 : 공시 → 사업보고서 → 분기보고서 → IR → 컨퍼런스콜
  • 산업 : 정부기관 → 산업협회 → 기업 공식자료 → 시장조사기관
  • 거시 : 중앙은행 → 정부기관 → IMF → OECD
  • 뉴스 : 기업공식 → 공시 → 정부 → 신뢰도 높은 언론
항목기본 분석기간
기업 개요 / 사업현재 기준
산업 분석최근 5년 + 향후 3~5년
성장성최근 5년 + 향후 3~5년
재무최근 5개년 + 최근 4개 분기
리스크 / 투자 Thesis현재 기준

사용 원칙
  • 본 템플릿은 기업의 1차 공통분석을 위한 것이다.
  • GO 판정 시 업종별 Template, 기업 생애주기 Template, 가치평가 Template 등 심층분석을 진행한다.
  • 최종 투자판단은 심층분석 이후 내린다.
